Les quatre fichiers inspectés sont en 1920 × 1080, H.264, à 25 ou 23,976 i/s. Le moteur les recadre bord à bord en 720 × 1280, sans carte ni cadre d’interface. Le manifeste canonique `rushes/manifest.json` porte les URL directes, tailles, métadonnées et empreintes complètes.

## Règle de publication

- les médias bruts sont téléchargés uniquement dans le cache du runner GitHub ou le stockage runtime ;
- ils ne sont jamais commités ;
- ils ne sont jamais ajoutés aux artefacts ni aux Releases ;
- seuls le MP4 monté, les contrats, les rapports, les empreintes et les preuves dérivées peuvent être publiés.
